A lightweight and modular health component built entirely in Blueprints for Unreal Engine 5.

Features:

Health system

Optional armor system

Simple damage and healing functions

Plug-and-play integration

The armor system is fully optional, allowing the component to work perfectly as a standard health system if armor is not required.

# Installation

In your main directory of your project (where the uproject is) if their isnt a "Plugins" folder create one. Then extract the zip file directly into the folder. Restart the project go to Edit->Plugins and it should be there.
